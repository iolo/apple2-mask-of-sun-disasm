# 한국어판 영문 입력 안내

게임 설명은 한국어로 표시되지만 **명령과 수수께끼 답은 영문 대문자**로 입력합니다.
`OK>` 뒤에 입력하고 RETURN을 누르세요. 소지품 이름 뒤 괄호에는 입력할 영문 이름이
표시됩니다. 예를 들어 `삽(SHOVEL)`의 입력 이름은 `SHOVEL`입니다.

| 목적 | 입력 예 |
| --- | --- |
| 주변 보기 | `LOOK` |
| 소지품 확인 | `INVENTORY` |
| 대상 살펴보기 | `LOOK 대상`, `EXAMINE 대상` |
| 물건 집기/내려놓기 | `GET 물건`, `DROP 물건` |
| 들어가기/나가기 | `ENTER 대상`, `EXIT 대상` |
| 북/남/동/서 | `N`, `S`, `E`, `W` |
| 북동/북서/남동/남서 | `NE`, `NW`, `SE`, `SW` |
| 왼쪽/오른쪽/앞/뒤 | `LEFT`, `RIGHT`, `FORWARD`, `BACK` |
| 위/아래 | `UP`, `DOWN` |
| 저장/복원 | `SAVE GAME`, `RESTORE GAME` |
| 소리 켜기/끄기 | `SOUND ON`, `SOUND OFF` |

표의 `대상`과 `물건`은 입력할 글자가 아니라 영문 이름을 넣는 자리입니다.
명령의 성공 여부는 현재 위치·물건·상태에 따라 달라집니다. 이름이 두 단어이면
공백을 유지하세요. 원래 엔진의 단어당 다섯 글자 처리 때문에 긴 단어도 정상
인식하지만, 입력 안내에는 읽기 쉬운 전체 철자를 사용합니다.

`[ 아무 키나 누르세요 ]`가 나오면 SPACE 등 아무 키를 눌러 계속할 수 있습니다.
`(Y/N)` 질문에는 `Y` 또는 `N`을 입력합니다. 수수께끼에서는 생각한 답을 영어로
입력하세요. 정답이나 비밀 단어는 이 안내에 싣지 않습니다.

r01 검수 자료에 포함된 입력 안내입니다. [디스크 교체·저장 및 플레이테스트 안내](playtest-r01.md)를
함께 참조하세요. 실제 퍼즐 문맥과 가독성의 사람 검수는 플레이 후 확인합니다.
