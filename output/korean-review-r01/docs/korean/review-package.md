# 한국어 번역 사람 검수 — 첫 번째 묶음

검수 대상은 **번역 초안 1,327항목과 명시적 제외 61항목**이다. 아직 승인된
번역은 없으며 실제 게임 디스크에는 시험 문자만 적용했다. PRD Step 3의
`Request and confirm human review`에 따라 번역 적용 전에 검수를 요청한다.

## 검수 자료

1. [원문·번역·문맥 검수표](review.md): 항목 ID로 수정 의견을 남긴다.
2. [용어집](../../assets/korean/glossary.json): 용어 40개, 방향 8개, 행동 20개와 문체 규칙.
3. [영문 입력 안내](input-guide.md)와 [수수께끼 검토](input-review.md).
   수수께끼 검토의 접힌 표와 관련 JSON에는 원작의 정답이 있다.
4. [제외 목록](exclusions.md): 초기화 전 안내, 독립 복원 오류, 기술 진단,
   입력 에코·프롬프트 등 영어를 유지하는 이유를 함께 검토한다.
5. [7×8 화면 미리보기](../../build/korean/layout-preview/index.html): 원문·번역·ID
   검색 및 문구 결합 표시. [검사 한계](layout-review.md)와
   [인벤토리·매체 결합 검사](composed-layout.md)도 함께 본다.

`tools/korean/review_package.py`는 이 자료와 화면 PNG, 원천 JSON, 항목별 검수
해시, 출처·검증 보고서를 하나의 폴더와 ZIP으로 묶는다. 폴더의 `README.md`부터
열면 된다. `manifest.json`의 카탈로그 해시가 검수 버전을 식별한다. 원본 게임
디스크나 실행 가능한 한국어판을 포함하지 않는다.

## 검토할 내용

- 정확성·문체: 인물, 행동, 방향, 위험, 단서와 결말의 의미가 보존되는지 확인한다.
  연속 `.P`에서는 한국어 어순에 따라 정보가 이웃 항목으로 이동하므로 묶어서 읽는다.
- 입력 가능성: 한국어 설명으로 행동을 추론하고 필요한 영문 명령·아이템명을
  알 수 있는지 확인한다. 명령·수수께끼 답은 영문 대문자로 입력한다.
- 수수께끼: 단서가 사라지거나 원문보다 정답을 더 드러내지 않는지 확인한다.
- 화면 분량: 문장이 빠지거나 잘리는지, 숫자·아이템·이어 쓰기 연결이 자연스러운지
  확인한다. 미리보기의 행 12/열 0은 가정이며 실제 화면 승인으로 취급하지 않는다.
- 제외 방침: 한글 초기화 불가·부분 복원 실패 때의 필수 영문 기술 안내를
  그대로 두어도 되는지 확인한다. ROM/Applesoft/DOS 셸 전체는 번역하지 않는다.

## 실현성 판정과 남은 위험

**추가 140K DOS 초기화 디스크 한 장으로 현재 초안이 들어간다.**
원래 A/B와 합쳐 세 장이며 저장 디스크는 별도다. ProDOS 전환은 필요하다고
판단하지 않았고 시작하지 않았다. 필요해지면 먼저 작업을 멈추고 사용자에게 알린다.

| 영역 | 현재 사용량 또는 여유 | 검수 변경 시 확인할 점 |
| --- | --- | --- |
| LC 글꼴 | 650글리프 / 5,200바이트 | 새 음절마다 8바이트 증가 |
| LC 상주 풀 | 4,089 / 4,096바이트 | 반복 문구 승격을 조정할 수 있으나 방·디스크 사용량도 변함 |
| LC 최대 방 풀 | 1,013 / 1,024바이트 | 가장 큰 ROOM 43.0은 11바이트 여유 |
| 메인 런타임 | 1,818 / 2,048바이트 | 코드 여유 230바이트 |
| A / B 디스크 | 3 / 6섹터 여유 | 768 / 1,536바이트. 파일별 섹터 반올림 포함 재검사 필요 |
| 추가 초기화 디스크 | 345섹터 여유 | 이 여유가 A/B나 LC 여유로 자동 전환되지는 않음 |

전체 합성 매체의 86자원 적재, 66명령 A→B 경로, 양면 저장 및 새 부팅 복원,
대표 뱀 장면의 입력 시간 보존이 각각 검증됐다. 37개 호스트 검사와 94개
인코딩 산출물의 재현도 통과했다. 현재 카탈로그에서 만든 세 합성 이미지는
앞서 실행 검증한 이미지와 바이트가 같다. [동등성 근거](../evidence/korean/output-audit-media-equivalence.json).

검수자가 문장을 억지로 줄여 여유에 맞출 필요는 없다. 수정 후 용량을 다시
계산하고 DOS/메모리 배치를 조정한다. 수정된 문구는 재검수한다.

승인 뒤에도 실제 한국어 화면의 커서·그림·페이지 전환, 지형 명사와 입력 안내의
전체 진행 검증, 나머지 시간 제한 장면, 엔딩과 최종 재빌드 검사가 남는다.
실제 Apple II+ 하드웨어 검증도 아직 없다. 이 번역 검수는 해당 실행 검증을
완료했다는 승인이 아니다.

## 수정과 승인 기록

의견은 `항목 ID → 수정안 또는 사유`로 남기거나 검수표의 `ko` JSON 값만 수정한다.
문맥·원문·ID·해시는 수정하지 않는다. 표 반영만으로 승인 처리하지 않으며
변경된 항목은 기존 승인이 있어도 무효화된다.

승인할 때는 검수 버전(카탈로그 해시), 승인 범위(전체 또는 항목 ID), 검수자와
보류 항목을 명시한다. 응답이 없거나 일부만 승인하면 나머지는 미승인 상태로
유지한다. `catalog.py check --require-approved`가 통과하기 전에는 실제 번역을
게임 디스크에 적용하지 않는다.
