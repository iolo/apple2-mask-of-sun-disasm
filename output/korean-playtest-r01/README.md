# Mask of the Sun — Korean r01 playtest

The 1,327 translations you approved are applied unchanged. Context and readability still need playtesting.

Boot **mask-of-sun-ko-extra.dsk** on an Apple II+ with 48K RAM and a 16K Language Card. When prompted, replace it with **mask-of-sun-ko-a.dsk** in the same drive and press RETURN. Insert B when requested. Commands remain English.

The fourth image, **mask-of-sun-ko-save.dsk**, is an initialized blank save disk. Use working copies. Saves are specific to this build; English and other-build saves are incompatible.

Verified in MAME: the 122-command ending route, B-side save/restore and fresh-boot restore, title pixel preservation, and 44 host tests. All three game disks match repeat builds byte for byte. Screenshot files under `screenshots/spoilers/` reveal the ending.

Read the [Korean playtest guide](docs/korean/playtest-r01.md) and [input guide](docs/korean/input-guide.md). For wording issues, note the preceding command and location and capture the screen.

These are three 140K DOS game disks plus a separate save disk. No ProDOS conversion was made. Full contextual acceptance and physical hardware verification are pending.

Font: Mask Korean 7x8, derived from GalmuriMono7 2.403. See [font provenance](assets/korean/font/source.json) and [SIL OFL 1.1](assets/korean/font/OFL.md).
