# 전체 합성 DOS 매체와 B면 저장·복원

2026-10-14: 전체 A/B 및 추가 초기화 디스크를 만들고 실제 Disk II/RWTS 적재와
B면까지의 진행·저장·새 부팅 복원을 검사했다. **번역 적용이나 사람 승인은 아니다.**
현재 초안의 메시지 길이를 사용하되 모든 풀 본문을 합성 문자로 바꾼다.
[검증 인덱스](../evidence/korean/full-media-validation.json)에 코드·결과·그림 해시와
재현 빌드 대조를 기록했다.

## 합성 자료와 실제 배치

`startup_disk.py --full-synthetic`은 초안을 호스트에서 인코딩한 다음, 디스크를
만들기 전에 모든 상주/방별 메시지 풀의 본문을 바꾼다. ASCII는 `X`, 한글은 `가`로
치환하며 공백·LF·종료자·1/2바이트 토큰 폭·인덱스·중복 주소를 보존한다. 바뀐
본문을 다시 중복 제거하지 않으므로 초안의 실제 파일 크기와 섹터 비용이 유지된다.
스크립트의 제어 흐름과 영문 입력 패턴은 그대로다. 폰트는 원래 650글리프를 유지한다.

| 매체 | 파일 수 | 여유 섹터 |
| --- | ---: | ---: |
| A | 63 | 3 |
| B | 76 | 6 |
| 초기화 | 12 | 345 |

원본 A/B의 파일명 전체를 유지한다. 비스크립트 원본 자산 50파일은 바이트를 대조한다.
interpreter/intrinsics는 조건부 소스 빌드이며 A의 START는 초기화 디스크로 부팅하라는
영문 안내다. 게임 A만으로 한국어 런타임을 초기화하지 않는다. 카탈로그·TS-list·VTOC
소유/여유 비트와 파일별 읽기 결과를 검사하며 B의 원래 트랙 1–2 영역도 재사용한다.

서로 독립적으로 만든 세 이미지와 부트·interpreter·intrinsics·runtime/font/resident
파일 총 9개가 바이트 단위로 일치했다. 합성 마스킹은 호스트에서 수행하며 게임
이미지에 초안 본문이 남지 않도록 최종 풀을 별도 디코더로 읽어 문자 허용 목록도 검사한다.
원래 영어 기술 안내·제외 문자열은 유지한다.

## 전체 86자원 적재

[전체 적재 증거](../evidence/korean/full-media-probe.json)는 실제 추가 디스크로
콜드 부팅해 LC 자산을 읽은 뒤 `$0800` 명령 경계에서 검사 하네스를 시작한다.
이 검사에는 **하네스/PC/요청 면 주입이 있다**. 게임 진행 검증으로 해석하지 않는다.

단일 드라이브에서 A 다음 B를 마운트하고 86개 스크립트 패키지를 모두 실제 로더로
읽었다. 스크립트와 LC 풀 바이트, 기록 범위 밖 main/LC 메모리, 런타임 코드,
상주 풀·폰트와 ROM 복귀를 대조한다. B의 DEATH, ROOM 23.0, ROOM 23.1,
ROOM 24.0에 할당된 트랙 1–2의 TS/본문 19섹터도 실제 읽기를 통과했다.

## 실제 진행과 B면 복원

[게임 진행 증거](../evidence/korean/full-game-probe.json)는 하네스 없이 콜드 부팅해
기존 66명령 경로를 키보드로 실행한다. 첫 피라미드·A→B 전환 후 B의 ROOM 34에서
저장하고 지프 밖으로 나간 다음 복원한다. 방 34·B면·지프 내부 상태와 원래 검증의
월드 배열 5구간(각 252바이트)이 복원 전 저장 상태와 일치한다.

별도 새 프로세스에서 같은 추가 디스크로 부팅하고 A의 시작 장면에서 RESTORE GAME을
실행했다. 저장 디스크 후 B를 요청하며 방 34, 월드 배열, 스냅샷에 저장된 수정 가능한
방 스크립트가 복구됐다. 풀 재적재가 저장된 스크립트를 덮어쓰지 않음을 대조한다.
명령 프롬프트마다 현재 파일명/면에 해당하는 LC 풀의 길이와 모든 바이트도 검사한다.
동일 세션 67회, 새 부팅 5회 검사가 통과했다.

[B면 저장 전 화면](../evidence/korean/full-synthetic-b-save.png)과
[새 부팅 복원 화면](../evidence/korean/full-synthetic-b-restored.png)은 시험 문자 출력이다.

두 게임 실행은 자연 키보드와 단일 드라이브 매체 교체만 사용한다. CPU/월드/스크립트
주입은 없다. 메시지 참조 실패는 0회이며 실행된 합성 한글 글리프와 LC 상주 자산을
계수/대조한다. 페이지 대기는 LIBRARY의 `!MORE` 루프 범위로, 유령의 안내 및 저장
매체 요청은 출력 메시지 ID로 인식한다. 번역된 화면에 영문 대사가 있다고 가정하지 않는다.
원래 `OK>^` 입력 프롬프트와 실험용 영문 runtime 안내는 계속 사용한다.

## 재현과 남은 범위

```sh
python3 tools/korean/verify_full_media.py \
  --rompath /path/to/roms --output build/korean/full-media-validation-new
python3 tools/korean/verify_full_game.py \
  --rompath /path/to/roms \
  --media build/korean/full-media-validation-new/fixture/media \
  --output build/korean/full-game-validation-new
```

출력 디렉터리는 새 경로다. 원본/기준선 디스크는 보존하며 실행 중에는 별도 복사본을
마운트한다. `test_synthetic.py`는 제어값과 같은 글리프 low byte, 중복 인덱스,
빈 문구 및 손상 풀을 포함해 마스킹을 검사한다. 호스트 검사 총 34개가 통과했다.

이 결과는 K3 이전 전체 합성 배치·A→B 전환·B면 새 부팅 복원의 기술 조건을
뒷받침한다. 전체 엔딩 경로, 나머지 시간 제한 장면, 승인 번역의 실제 UI/화면,
그림 자산의 버전 혼용 검출 및 물리 Apple II+ 검증은 완료하지 않았다. 방 풀의
작은 크기 여유와 번역 변경 후 재패킹도 계속 확인해야 한다. ProDOS 이식은 시작하지 않았다.
